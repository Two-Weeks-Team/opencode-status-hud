# OpenCode HUD Default Configuration (Alpha)

## Core Defaults

- Profile: `minimal`
- Cooldown: `1000ms`
- Max state entries: `200`

## Emission Defaults

- Coexistence mode: `toast-only`
- Coexistence verbosity: `low`
- Prompt fallback profile: `minimal`

## Safety Defaults

- Unknown events are ignored.
- Malformed payloads are dropped without throw.
- Display values are sanitized and truncated by policy.
