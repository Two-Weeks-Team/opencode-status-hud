# OpenCode HUD Quickstart (Alpha)

## Prerequisites

- Node.js 22+
- npm

## Setup

```bash
npm install
```

## Validation Commands

```bash
npm run typecheck
npm run test
npm run build
npm run ci
```

## Runtime Notes

- Baseline runtime is plugin-local and does not require `oh-my-opencode`.
- Default output posture is low-noise (`toast-only`, conservative prompt fallback).
